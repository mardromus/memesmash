# 🧠 Meme Brainrot Arena

An addictive meme classification game with a **real neural network** that learns your meme taste!

## 🎮 How to Play

1. **Swipe memes** left (Normie 👎) or right (Dank 👍)
2. Build **combos** for bonus points
3. Watch your **brainrot meter** grow
4. The AI learns your preferences in real-time!

## ✨ Features

- 🤖 **Real Neural Network** - Backpropagation AI that learns from your swipes
- 🌙☀️ **Light/Dark Mode** - Toggle between themes
- 📊 **3,300+ Memes** - Massive dataset from Reddit
- ⚡ **Progressive Difficulty** - Gets harder as you play
- 🔥 **Combo System** - Screen shake, confetti explosions
- 💾 **High Score Tracking** - Persisted in localStorage

## 🚀 Quick Start

```bash
# Clone the repo
git clone https://github.com/mardromus/memesmash.git
cd memesmash

# Start a local server
python -m http.server 8080

# Open in browser
# http://localhost:8080
```

## 🛠️ Tech Stack

- Vanilla JavaScript (no frameworks)
- CSS Variables for theming
- Canvas API for neural visualization
- Custom neural network implementation


| Action | Control |
